# 5 Advanced RAG Context Expansion Techniques

Vector search with basic chunking may be killing the accuracy of your rag agent. Here are five context expansion methods that can solve this problem for structured documents. Number one is full document expansion. You provide the entire file to the agent to answer the question. The second is neighbor expansion where you grab adjacent chunks to what were initially retrieved from the vector store. The third is section expansion where you pull in both sibling and child chunks based on the document structure. Next up is parent expansion where you grab all of the chunks of the parent heading. And finally, we have agentic expansion where an agent can intelligently traverse the document structure and figure out which parts of the document it needs to accurately answer the question. Implementing dynamic retrieval like this will dramatically improve your AI agents accuracy.
