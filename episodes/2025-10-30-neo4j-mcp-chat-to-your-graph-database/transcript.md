# Neo4j + MCP - Chat to Your Graph Database

Knowledge graphs are incredibly powerful. However, learning complex query languages like cipher has always been a pretty steep barrier to entry. All of that is history now thanks to the Neo4j MCP and claw desktop. You can now literally chat to your graph database using natural language. You could say, "Give me a list of all orders from Michael Chen along with any open support tickets." The AI automatically generates the cipher query, executes it against the graph database, and returns the results in plain English. And if it gets the query wrong, it can correct itself and go again. Cipher is quite a readable language, so you get to view and approve each query just so you know it's not going off track. Or you could always set up a readonly user to make sure it doesn't do anything destructive. The AI uses the MCP server to interact with and understand the graph schema to dynamically create and generate the queries. So this completely removes the barrier to entry for those working with knowledge graphs.
